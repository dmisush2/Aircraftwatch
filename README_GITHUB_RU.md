## Загрузка на GitHub
Распакуйте ZIP и загрузите его содержимое в корень репозитория, а не сам ZIP. Сохраните каталоги worker/, scripts/, tests/, dist/ и скрытую папку .openai, а также package.json. На Mac скрытые файлы показываются сочетанием Command+Shift+точка.

## Сборка и проверки
Нужны Node.js 22 или новее и Bash. Зависимостей npm для сборки нет.

```sh
npm run build
npm run validate
node --test tests/*.test.mjs
```

Это серверное приложение Cloudflare Workers с хранилищем R2 (binding BUCKET). GitHub Pages не воспроизводит серверную часть. Для переноса на другой хостинг нужна отдельная настройка. Исходный .openai/hosting.json относится к существующему сайту ChatGPT Sites.

API-ключ ADSB_RAPIDAPI_KEY задаётся секретом окружения. Серверные данные R2, зоны, список регистраций и настройки уведомлений не экспортированы. Связь фоновых уведомлений с Ramp Schedule при переносе требует отдельной настройки.

Все 13 исходных файлов сохранены без изменений. README_GITHUB_RU.md и SOURCE_VERSION.json добавлены для экспорта. Опубликованный сайт не изменён.
